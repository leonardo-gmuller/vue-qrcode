# Vue QR Code Generator

This project is a **QR Code Generator** built with **Vue 3** and **Vite**. It allows users to customize and generate QR codes with various styles and options, including the ability to download the generated QR codes in different formats.

## Features

- **Customizable QR Codes**: Modify colors, styles, and corner shapes.
- **Image Embedding**: Add custom images to the QR code.
- **Real-Time Preview**: See changes instantly as you customize.
- **Download Options**: Save QR codes in PNG, JPEG, WEBP, or SVG formats.

## Tech Stack

- **Vue 3**: Frontend framework.
- **Vite**: Fast development build tool.
- **PrimeVue**: UI components for Vue.
- **qr-code-styling**: Library for generating customizable QR codes.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/leonardo-gmuller/vue-qrcode.git
    cd vue-qrcode
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Start the development server:
    ```bash
    npm run dev
    ```

4. Open your browser and navigate to `http://localhost:5173`.

## Usage

1. Enter the desired text or URL for the QR code.
2. Customize the QR code's appearance:
    - Change dot styles, corner styles, and colors.
    - Add a background image.
3. Preview the QR code in real-time.
4. Download the QR code in your preferred format.

## Scripts

- `npm run dev`: Start the development server.
- `npm run build`: Build the project for production.
- `npm run preview`: Preview the production build.
